# План работ

| Этап | Срок | Содержание | Готово, когда |
|---|---|---|---|
| 0. Требования | 2 недели | Интервью 3–5 специалистов клиники, группы детей, протокол занятия, форма согласия на видео, осмотр кабинета, выбор положений ящика | Документ требований подписан клиникой; список режимов и полей отчёта согласован |
| 1. Прототип | 6–8 недель | Сервис датчика (Kinect v2 + FakeSensor), рендер с режимами «Спокойная карта», «Классика», «Контраст», мастер калибровки, сеансы с записью трёх потоков и скриншотами, консоль на планшете, автозапуск, наблюдатель | Пилот в клинике: 20 сеансов подряд без настройщика; специалисты подтверждают, что консоль понятна |
| 2. Рабочая версия | 6–8 недель | Задания, подписи на песке, профили детей, показатели и отчёты PDF, вода, PJLink, резервное копирование, ограничитель мерцания с автотестом, суточный тест | Все тесты надёжности пройдены; клиника работает месяц без выезда |
| 3. Продукт | 3–4 месяца | Orbbec Femto Bolt через общий интерфейс, образ системы и мастер первого запуска, лицензирование, два положения ящика в комплекте, документация, обучение, удалённая поддержка, вторая площадка | Вторая установка развёрнута по инструкции за день без разработчика |

Тесты перед сдачей каждого этапа — раздел 5 в `architecture.md`.
